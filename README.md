# 香川高専 EC 単位管理ツール

香川高専・電気情報工学科の取得単位を管理するWebツールです。科目にチェックを入れると、取得単位と進級・学校推薦・卒業の単位数条件が自動で更新されます。

## アクセス

<https://zeas0608.github.io/kagawa-ec-credits/>

スマホ・タブレット・PCのブラウザで使えます。インストールやログインは不要です。

## 使い方

1. **科目管理**で、取得済みの科目の「単位取得」をチェックします。1〜3年の必修は初期状態で取得済みです。科目番号から個別シラバスを開けます。
2. **資格認定**で資格・検定の取得状況を選びます。学校認定済みの資格を集計します。学校が認定した学外科目は「その他の認定単位」に入力します。
3. **ダッシュボード**で、取得・認定済みの確定単位と、各条件までの不足単位を確認します。

入力と科目・資格欄の開閉状態は、開いたブラウザに自動保存されます。端末やブラウザを変えると、保存内容は引き継がれません。画面下の「データを初期化」で初期状態に戻せます。

## 集計について

- 4・5年の両方で取得済みにした同一科目は、4年に一度だけ計上します。
- 資格の同じ太枠グループでは、学校認定済みのうち最大の単位数を計上します。TOEICのオンラインIPテストは認定対象外です。
- 5年への進級は、1〜3年の必修を修得済みとして、4年までの累計128単位と電気情報工学実験Ⅱの修得を確認します。
- 就職の学校推薦では、4年までの専門累計55単位と4年の専門必修10単位を確認します。進級と学校推薦の累計には、現時点の対象となる資格・学外認定単位を反映します。
- 卒業の単位数条件は総計167単位・一般75単位・専門82単位です。全学年の必修修得も必要なため、4・5年の未修得必修科目数を別に表示します。 [学校の進級・卒業認定規程](https://www.kagawa-nct.ac.jp/general_affairs/rules/05-01.pdf#page=2)

## データの出典

- 4・5年の授業科目と開講学年。[2026年度シラバス](https://syllabus.kosen-k.go.jp/Pages/PublicSubjects?school_id=39&department_id=32&year=2026&lang=ja)
- 1〜3年の必修単位と選択科目。[2025年度シラバス](https://syllabus.kosen-k.go.jp/Pages/PublicSubjects?school_id=39&department_id=32&year=2025&lang=ja)・[2025年度学校要覧](https://www.kagawa-nct.ac.jp/prospectus/publication/yoran/yoran_jp2025_03.pdf)
- 資格認定の対象、単位数、太枠グループ。[資格認定規程の別表](https://www.kagawa-nct.ac.jp/general_affairs/rules/05-04.pdf#page=3)

## ローカルで動かす

リポジトリのルートで次を実行し、ブラウザで [http://localhost:8000/](http://localhost:8000/) を開きます。

```sh
python3 -m http.server 8000
```

HTML・CSS・JavaScriptで動作します。単位計算と保存形式のテストは `npm test` で実行できます。
